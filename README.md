# NoteFlow - Flutter + Django JWT Authentication App

## 📌 Project Overview

NoteFlow is a full-stack authentication application built using:

- Flutter (Frontend)
- Django (Backend)
- JWT Authentication
- REST API

This project demonstrates how Flutter communicates with a Django backend using JWT authentication.

---

# 🚀 Features

✅ User Login Authentication  
✅ JWT Token Generation  
✅ Flutter Frontend UI  
✅ Django REST API Backend  
✅ Android Emulator & Real Device Support  
✅ Secure API Communication  

---
